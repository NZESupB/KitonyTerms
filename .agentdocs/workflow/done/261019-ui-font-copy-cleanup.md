# 界面字体与文案精简

## 目标与范围

用户批准实施：修复界面自定义字体名称与回退；删除文件管理“恢复自适应列宽”按钮及独立点击逻辑；精简中英文提示与占位。列宽拖拽、键盘调整、持久化、双击恢复继续保留。终端字体渲染不在此次修复范围。

## 决策与实现

- `fonts::css_ui_font_family` 以单个 CSS 字符串表达完整字体名，处理引号、反斜杠、控制字符与 NUL；空配置仍为 `None`。数字开头、中文、括号、逗号等不再通过删除字符改变名称。通用字体族保留关键字语义，自定义结果附加 `var(--kt-ui-font-default)`。终端原有字体栈表达式路径不变。
- `app.css` 明确 `font-optical-sizing: auto`，沿用原生平滑策略和字号比例。没有引入全局灰阶平滑、文字描边或整体 transform/zoom；这些配置无法由当前资料认定为用户发虚的修复依据。
- `SftpColumns` 删除恢复按钮及独立 onclick、翻译字段和工具栏样式。保存失败才渲染状态行；JS 双击恢复的空数组消息与共享保存路径保留。
- 删除命令历史说明、设置重复说明、连接列表/空工作区副文案、运维独立 SSH 通道说明；缩短字体、编辑器与同步提示。
- 更新状态说明为 `Option`，仅有必要补充信息时渲染段落；开关说明及 `aria-describedby` 同步条件渲染。代理长说明置于原生 `details`，本机偏好说明集中一处。
- 中英文翻译同步删除未引用字段；连接示例缩短，去掉端口/用户名的重复占位；保留密码留空语义和同步、覆盖、主机信任、重启影响等必要信息。补齐相关输入的可访问名称。
- 命令历史在英文 140% 字号下发现 3–4px 滚动溢出，根因是 `opacity: 0` 的按钮提示气泡仍参与滚动范围。局部将气泡右对齐向面板内部展开，保留原控件尺寸。

## 验收边界

浏览器 SSR 夹具的原生适配仅用于 DOM、CSS 与浏览器交互核验，不代表生产 Dioxus 事件链路端到端验证。未提供目标第三方字体、操作系统与系统缩放比例，因此当前不能认定字体 Hinting、合成字重或系统抗锯齿为用户发虚的唯一根因。

具体字体的原生 WebView 视觉对照、Windows ClearType/跨屏 DPI、真实配置重启持久化与 SSH 下文件列宽交互仍需实机验收。DPR 模拟不替代上述验收。
