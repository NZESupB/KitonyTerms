# 动态终端刷新

## 目标与边界

修复 Vim/docker stats 类动态输出的中间帧闪烁与同步更新挂起，保留缓冲区选区及跨屏复制。不改 TERM、远端配置或 GPU 设置，不发布或替换本机应用。

已核查：SSH Data/ExtendedData 每块立即快照；UI 状态每 100ms 才同步；vte 同步更新未接入事件循环截止时间。字体 W 测量与 ch 格宽存在理论不一致，只有定向验证复现才扩大修改。

## 实施方案

- TermEngine 统一保存输出待渲染状态：8ms 静默窗口、16ms 首块最大等待；不丢原始输出，快照按需要构建。队列满时保留待渲染状态并限频重试。
- 同步更新期间等解析器截止时间；超时调用 stop_sync，推进内容版本并处理生成的 PTY 事件。正常结束沿用上游解析，尺寸改变/退出处理缓冲尾部。
- 宿主与容器使用相同的引擎调度接口，立即交互帧保留；关闭前提交尾帧。
- UI 在 16ms 事件泵内同步发生变化的会话；确认弹窗与通知保留 100ms 检查。避免无变化仍更新信号。

## 验证边界

有限合帧不能保证未使用同步更新协议且分块间隔超过预算的画面绝对原子。真实原生 WebView/系统剪贴板与实际远端 Vim/Docker 的表现需与夹具证据区分。沿用项目现有正式测试；临时实验放 scratch。

## 验证结果

- 生产代码的 Rust format/check、默认和全特性 Clippy、8 项 Node 桥接回归、JS 语法与 diff 检查通过。
- 完整 Rust 串行运行 615 项通过/1 项 OpenSSH 专项按现有规则忽略；默认并发再次在既有 single_instance 锁测试失败，单独运行通过，具体并发原因未证明且未扩大修改。最后仅补强测试：重复尺寸后保留实际选区及坐标、队列恢复后送出最新网格、DSR 证明同步缓冲在旧尺寸下解析；9 项定向测试复跑通过。
- 当前源码重建的真实 TermEngine/生产 Terminal SSR、CSS、选区 JS 和锁定版本 native_eval 通道夹具：70 项动态渲染/尺寸断言及 267 项选区断言通过。连续输出最终帧完整；40ms 分块同步输出只提交完整帧；缺结束标记约 156ms 自动释放；12 组窗口/字体/字号组合尺寸稳定，未据此修改字体/几何。SSR 手工应用帧不能代替 Dioxus 原生 DOM 更新和真实显示器观感验收。
- 保留永久回归，临时夹具/日志位于会话 scratch；未暂存、提交、发布、改 TERM 或替换本机应用。原生 WebView/系统剪贴板、真实远端 Vim/docker stats 与手机端仍待实机验收。
